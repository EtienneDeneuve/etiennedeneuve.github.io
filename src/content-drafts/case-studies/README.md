# Brouillons — modèles éditoriaux (case studies)

Ces fichiers **ne sont pas publiés** et **ne participent pas au build**.

Ils servent de modèles pour rédiger de futures études de cas vérifiables :

- remplacer « Client A » par un contexte anonymisé ou nommé avec consentement ;
- remplacer les métriques `[PLACEHOLDER: …]` par des métriques `verified: true` avec source ;
- ajouter des preuves structurées (`evidence`) avec URL et description ;
- définir `disclosureLevel` : `public`, `anonymized` ou `confidential-summary`.

Pour publier une étude, déplacez-la dans `src/content/caseStudies/` et validez avec `bun run validate-publication`.

Voir [`docs/evidence-policy.md`](../../docs/evidence-policy.md).
